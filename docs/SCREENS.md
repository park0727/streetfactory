# 화면 목록

1차 범위 전 화면 구현 완료 (2026-09-15). 각 화면의 구현 파일은 `src/app/(app)/<라우트>/` 아래에 있다.

라우트는 `src/app/(app)/…`. 모든 화면은 로그인 필요. 좌측 사이드바(PC) / 하단 탭 + 드로어(모바일).

| # | 라우트 | 화면 | 핵심 요소 |
|---|---|---|---|
| 0 | `/login` | 로그인 | 이메일·비밀번호. 첫 로그인 시 비밀번호 변경 강제 |
| 1 | `/` | 대시보드 | KPI 카드 4개(총 재고평가액, 당월/누적 매출, 매출이익·평균마진율, 발주필요 품목수), 월별 매출·이익 콤보 차트, 카테고리별 재고평가액 도넛, 수입국별 입고 건수·비용 표 |
| 2 | `/parts` | 부품 마스터 | 검색(코드·이름·호환기종), 카테고리/제조사/상태 필터, 등록·수정 모달, 엑셀 다운로드, 엑셀 업로드(`/parts/import`) |
| 3 | `/inventory` | 재고 현황 | 기초·입고·판매·현재·안전재고, 상태 뱃지, 미달 행 강조, 평가액, 엑셀 다운로드, 실사 조정 모달 |
| 4 | `/entry` | 입출고 간편 등록 | PC 2단(좌 판매 / 우 입고), 모바일 탭. 하단 최근 트랜잭션 5건 |
| 4a | 판매 폼 | | 전표번호 자동, 출고일, 거래처, 채널, 라인 여러 개(부품 검색 셀렉터, 수량, 단가 자동입력 후 수정). 라인별 가용재고·초과 경고. 합계·예상이익·마진율 |
| 4b | 입고 폼 | | 입고번호 자동, 입고일, 공급사(→국가 자동), 통화·환율, 관세·부대비용, 운송방식, 통관상태, 라인 여러 개(부품, 수량, 외화단가). 총 입고비용·개당 실질원가 실시간 |
| 5 | `/partners` | 거래처 | 목록 + 실적(출고건수, 누적금액, 최근거래일), 등록·수정 모달 |
| 6 | `/ledger/partners` | 거래처 원장 | 거래처·기간 필터, KPI 5개(건수, 수량, 금액, 이익, 마진율), 라인 단위 원장 표, 정렬·페이징, 엑셀 |
| 7 | `/ledger/sales` | 판매 원장 | 전표 목록(행별 수정·삭제) → 상세 → 수정(`/ledger/sales/[id]/edit`, 전표번호 유지, 되돌린 뒤 재확정). 삭제는 재고 복원 |
| 8 | `/ledger/inbound` | 입고 원장 | 전표 목록(행별 수정·삭제) → 상세 → 수정(`/ledger/inbound/[id]/edit`, 되돌린 뒤 재확정·평균원가 재계산). 엑셀 라인 업로드(`/ledger/inbound/import`) |
| 9 | `/settings/users` | 사용자 관리 (admin) | 생성(이메일+임시비번), 역할, 모듈 플래그, 비활성화, 비번 초기화 |
| 10 | `/settings/master` | 기준 데이터 | 카테고리, 공급사, 판매채널 목록 관리 |
| 11 | `/settings/profile` | 내 정보 | 비밀번호 변경 |

## 공통 UI 규칙
- 숫자 우측 정렬, `₩#,##0`. 마진율 소수 1자리.
- 상태 뱃지: 정상 green, 안전재고 부족 amber, 품절 red. 운영상태: 운영중 slate, 일시품절 amber, 단종 gray.
- 표 헤더 sticky. 긴 표는 페이징 50행.
- 부품 셀렉터: `코드 | 부품명 | 호환기종` 라벨, 세 필드 모두 검색, 코드 정확 일치 시 즉시 선택.
- 저장 후 토스트, 폼은 초기화하되 날짜·거래처는 유지(연속 입력 편의).
