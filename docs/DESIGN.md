# 디자인 시스템

주제: 오토바이 수리·수입 부품 업체의 내부 ERP. 직원 2~3명이 PC 와 휴대폰에서 하루 종일 조회·입력한다.
톤: 정비소의 재료감(강판, 네이비 작업복, 안전 표식)을 빌린 **산업용 네이비 & 슬레이트**. 장식은 없고 위계와 밀도로 승부한다.
요구사항 문서의 "비즈니스 네이비 & 슬레이트 그레이" 지시를 그대로 따른다.

## 색 (토큰은 src/app/globals.css)

| 역할 | 값 | 용도 |
|---|---|---|
| ground | `#F4F6F9` | 페이지 바탕 (푸른 기 도는 오프화이트) |
| surface | `#FFFFFF` | 패널, 표, 폼 |
| ink | `#0E1729` | 본문 텍스트 |
| navy | `#16243D` | 사이드바, 로그인 좌측 패널 |
| navy-action | `#1D3260` | 기본 버튼 |
| steel | `#5B6B82` | 보조 텍스트, 라벨 |
| hairline | `#DCE2EA` | 테두리, 그리드 |
| signal | `#F26B1D` | 액센트. **활성 메뉴 레일, 브랜드 마크, 강조 1곳** 에만 쓴다. 데이터 영역에는 쓰지 않는다 |
| ok / warn / critical | `#1E8E4B` / `#B45309` / `#C62828` | 재고 상태. 항상 라벨과 함께, 색만으로 의미를 싣지 않는다 |
| chart 1~4 | `#2A78D6` `#EB6834` `#1BAF7A` `#EDA100` | 차트 계열색 (dataviz 검증 팔레트, 고정 순서) |

## 서체

| 역할 | 서체 | 용도 |
|---|---|---|
| display | Barlow Semi Condensed 600/700 | 브랜드 워드마크, 페이지 제목 (라틴만. 한글은 body 로 폴백) |
| body | IBM Plex Sans KR 400/500/600 | 본문, 표, 폼, KPI 숫자 |
| mono | IBM Plex Mono 500 | 부품코드, 전표번호, 거래처코드 |

크기: 본문 13px(표) / 14px(폼). 제목 22px display. 표 헤더 11px 대문자 자간 0.06em. KPI 값 26px semibold(비례 숫자). 표 숫자는 tabular-nums.

## 레이아웃

- PC: 좌측 232px 네이비 사이드바 + 콘텐츠. 사이드바 활성 항목은 좌측 3px signal 레일 + 밝은 배경.
- 모바일: 상단 네이비 바(메뉴 드로어) + 하단 탭 4개(대시보드·입출고·재고·부품).
- 페이지 헤더: 제목/설명 좌, 액션 우. 그 아래 필터 행 → 표.
- 패널: 흰 바탕, 1px hairline, 6px 라운드, **그림자 없음**. 그림자는 다이얼로그·팝오버에만.
- 표: 헤더 sticky, 행 hover 워시, 숫자 우측 정렬, 상태는 칩(점 + 라벨).
- 상태 인코딩: 재고 부족 행은 좌측 2px warn 스트라이프, 품절은 critical 스트라이프.

## 카피

버튼은 일어나는 일을 그대로 쓴다: "저장", "출고 등록", "입고 확정". 오류는 원인과 해결을 한 문장으로.
